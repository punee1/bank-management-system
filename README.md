# Bank Management System

# Overview
This is a desktop-based Bank Management System developed using Java Swing and MySQL.
The application simulates an ATM system and allows users to perform basic banking operations through a graphical user interface.

# Features
- User Login
- Account Creation
- Deposit Money
- Withdraw Money
- Fast Cash
- Balance Enquiry
- Mini Statement
- PIN Change
- Transaction History
- MySQL Database Integration

# Technologies Used
- Java
- Java Swing
- JDBC
- MySQL
- NetBeans IDE

# How to Run
1. Open the project in NetBeans or your preferred Java IDE.
2. Create the required MySQL database and tables.
3. Update the database username and password in the source code.
4. Run the project.
